System Design

Architecture Overview

System Components

  • Web Interface: customer.html (user portal), index.html (admin panel)
  • Server: Node.js + Express (handles uploads, payments, API)
  • Arduino R4 WiFi: IoT payment verifier (polls server, verifies payments)
  • Hardware Sensors: RGB LED, Buzzer, IR Proximity Sensor
  • Printer Agent: Downloads files and sends to HP LaserJet P1108
  • Cloudinary: Cloud storage for uploaded PDFs
  • ThingSpeak: IoT analytics platform for real-time monitoring
  • HP LaserJet P1108: Physical printer (USB connected to computer)

Why This is IoT

  • Wireless Communication: Arduino uses WiFi (no USB to printer)
  • Cloud Connectivity: Polls cloud server for jobs
  • Independent Intelligence: Arduino verifies payments autonomously
  • Distributed System: Components communicate wirelessly
  • Sensor Integration: IR sensor, RGB LED, buzzer for smart feedback
  • Cloud Analytics: ThingSpeak platform for real-time data visualization
  • Scalable: Can add multiple Arduino units
  • Remote Monitoring: Real-time status via Serial Monitor and ThingSpeak
How It Works

Complete System Flow

From upload to printing in 12 automated steps

01

User Uploads PDF

User opens customer.html and selects a PDF file. The file is uploaded to Cloudinary cloud storage with secure CDN delivery.

02

PDF Analysis & Page Count

Server analyzes the PDF using pdf-parse library. Counts total pages (e.g., 5 pages). Creates a job with status: pending, payment: unpaid. Generates unique ticket number starting from 1000.

03

User Selects Print Options

User chooses: Black & White (₹2/page) or Color (₹5/page). Selects number of copies (1-10). System calculates total price: (Pages × Price) × Copies.

04

Payment Processing

User enters email and processes payment through multi-method gateway (UPI, Card, Net Banking). Server generates Payment ID and Receipt. Updates job: status → approved, payment → paid.

05

Arduino Polls Server

Arduino Uno R4 WiFi continuously polls server via WiFi every 5 seconds. Sends request: GET /api/jobs. Looks for jobs with: status = approved AND payment = paid.

06

Arduino Detects Paid Job

Arduino finds the paid job in server response. Extracts: Job ID, Ticket Number, Payment ID, File URL. Displays on Serial Monitor with banner.

07

Arduino Verifies Payment

Arduino makes independent verification: GET /api/receipt/:paymentId. Checks if payment is legitimate. If verified, proceeds to print.

08

Hardware Sensors & Feedback

RGB LED shows status (Green=idle, Blue=printing, Yellow=waiting, Red=error). Buzzer provides audio feedback. IR Proximity Sensor detects paper removal.

09

Printer Agent Downloads File

printer-agent/agent.js running on computer detects the paid job. Downloads PDF from Cloudinary URL.

10

Print on HP LaserJet P1108

Printer agent sends file to HP LaserJet P1108. Document prints with selected options (B&W or Color) for all copies.

11

ThingSpeak Analytics Update

Server automatically updates ThingSpeak IoT Platform every 15 seconds. Tracks: Total Jobs, Pages, Revenue, Queue, Color Ratio, Latest Ticket, Printer Status, Paper Status.

12

Success

User receives printed document. Receipt with ticket number saved in browser. Job marked as completed. Ready for next print job.
