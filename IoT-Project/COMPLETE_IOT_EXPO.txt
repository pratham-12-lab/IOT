PROJECT OVERVIEW
================================================================================

PrintBridge is a complete Internet of Things (IoT) cloud printing system that
delivers "Printer as a Service" (PaaS) capabilities. The system combines cloud
computing, wireless communication, and intelligent hardware to provide an
automated, payment-enabled printing service.

Key Features:
- Cloud-based document upload and storage (Cloudinary)
- Online payment processing with receipt generation
- Arduino IoT controller for independent payment verification
- Automatic printing on HP LaserJet P1108
- Real-time analytics via ThingSpeak IoT platform
- Ticket-based job tracking system
- Support for multiple copies (1-10)
- Black & White (₹2/page) and Color (₹5/page) printing

COMPONENTS BREAKDOWN
================================================================================

1. CUSTOMER PORTAL (printbridge/ui/customer.html)
   - User-friendly interface for document upload

2. WEB SERVER (printbridge/server/)
   - Express.js backend API

3. ARDUINO CONTROLLER (printbridge/arduino/)

4. PRINTER AGENT (printbridge/printer-agent/)

   - Persistent job history storage

5. CLOUD SERVICES
   - Cloudinary: PDF and image storage
   - ThingSpeak: IoT analytics and visualization
   - Render: Web server hosting (production)

PRICING MODEL
================================================================================

Black & White Printing:
- Rate: ₹2 per page
- Suitable for text documents
- Cost-effective for large volumes

Color Printing:
- Rate: ₹5 per page
- Suitable for images and graphics
- Higher quality output

Multiple Copies:
- Range: 1-10 copies per job
- Automatic price calculation
- Subtotal and total pricing display

Price Calculation Formula:
  Subtotal = Pages × Price per Page
  Total = Subtotal × Number of Copies

Examples:
- 5 pages, Black & White, 1 copy: 5 × ₹2 × 1 = ₹10
- 5 pages, Black & White, 3 copies: 5 × ₹2 × 3 = ₹30
- 10 pages, Color, 5 copies: 10 × ₹5 × 5 = ₹250

WORKFLOW
================================================================================

Step 1: Document Upload
1. Customer accesses customer portal
2. Selects upload type (PDF or Images)
3. Uploads document to Cloudinary
4. System analyzes PDF for page count
5. System generates unique job ID and ticket number

Step 2: Print Configuration
1. Customer selects print mode (B&W or Color)
2. Customer enters number of copies (1-10)
3. System calculates total price
4. Customer enters email for receipt

Step 3: Payment Processing
1. Customer initiates payment
2. Payment gateway processes transaction
3. Job status updated to "paid" and "approved"
4. Receipt generated and sent to customer

Step 4: Arduino Verification
1. Arduino polls server every 5 seconds
2. Arduino checks for paid and approved jobs
3. Arduino verifies payment with server
4. Arduino triggers print command

Step 5: Printing
1. Printer agent downloads PDF from Cloudinary
2. Printer agent sends to HP LaserJet P1108
3. Printer prints specified number of copies
4. Job marked as "printed" on server
5. Arduino displays completion message

Step 6: Paper Collection
1. IR sensor detects paper in output tray
2. Arduino beeps to remind user
3. User collects printed pages
4. System ready for next job

HARDWARE SPECIFICATIONS
================================================================================

Arduino Uno R4 WiFi:
- Microcontroller: Renesas RA4M1 (Cortex-M4)
- Clock Speed: 48 MHz
- Flash Memory: 512 KB
- RAM: 32 KB
- WiFi: 2.4 GHz (802.11 b/g/n)
- Operating Voltage: 5V
- Digital I/O Pins: 22
- Analog Input Pins: 6

Sensors and Peripherals:
- RGB LED: Common cathode, PWM capable
  - Red: Pin 6
  - Green: Pin 5
  - Blue: Pin 3

- Buzzer: Active piezo buzzer
  - Pin: 2
  - Frequency range: 500Hz - 2000Hz

- IR Proximity Sensor: Analog output
  - Pin: A0 (Analog Input)
  - Detection threshold: 512 (midpoint)
  - HIGH (>512): Paper detected
  - LOW (<512): No paper

- 16x2 LCD Display: HD44780 compatible
  - RS: Pin 12
  - E: Pin 11
  - D4: Pin 10
  - D5: Pin 9
  - D6: Pin 8
  - D7: Pin 7

HP LaserJet P1108:
- Printer Type: Laser
- Print Speed: Up to 18 ppm (A4)
- First Page Out: <8.5 seconds
- Resolution: 600 x 600 dpi
- Connection: USB 2.0

SERVER API ENDPOINTS
================================================================================

POST   /api/upload              - Upload PDF to Cloudinary
POST   /api/upload-images       - Upload multiple images, convert to PDF
POST   /api/calculate-price     - Calculate print price
POST   /api/payment/:id         - Process payment for job
GET    /api/receipt/:paymentId  - Get payment receipt
GET    /api/verify-payment/:id  - Verify payment (Arduino)
POST   /api/approve/:id         - Approve job for printing
GET    /api/jobs                - Get all jobs
POST   /api/jobs/:id/printed    - Mark job as printed
DELETE /api/jobs/clear-all      - Clear all jobs (admin)
DELETE /api/jobs/:id            - Delete specific job (admin)
GET    /api/shop-status         - Get shop status
POST   /api/shop-status         - Update shop status (admin)

PRINTER AGENT CONFIGURATION
================================================================================

Configuration File: printer-agent/config.js

Key Settings:
- SERVER_URL: Cloud server URL (e.g., https://printbridge.onrender.com)
- POLL_INTERVAL: Job polling frequency (default: 5000ms)
- PRINTER_NAME: Local printer name (default: HP LaserJet Professional P1108)
- DOWNLOAD_DIR: PDF download directory

Print Methods (in order of preference):
1. PDFtoPrinter (Most reliable)
2. SumatraPDF (Alternative)
3. Adobe Acrobat Reader (Fallback)
4. PowerShell (Last resort)

ARDUINO CODE STRUCTURE
================================================================================

Main Functions:
- setup(): Initialize hardware, WiFi, and LCD
- loop(): Main polling and status checking
- checkForPaidJobs(): Poll server for new jobs
- processJobs(): Parse and process job data
- verifyPayment(): Verify payment with server
- triggerPrint(): Send print command to computer
- reportPrintStatus(): Update job status on server

Helper Functions:
- connectWiFi(): Connect to WiFi network
- setStatusColor(): Update RGB LED status
- playCollectionReminderTone(): Beep for paper collection
- playErrorTone(): Beep for errors
- playStartupTone(): Beep on startup
- isPaperDetected(): Check IR sensor for paper
- blinkLED(): Visual confirmation

Status Colors:
- Green (IDLE): System ready, waiting for jobs
- Blue (PRINTING): Printing in progress
- Yellow (WAITING): Waiting for paper collection
- Red (ERROR): Error condition

TROUBLESHOOTING
================================================================================

Arduino Issues:
- Can't connect to WiFi: Check SSID and password
- Can't reach server: Verify SERVER_HOST (no https://)
- Serial monitor shows errors: Check WiFi signal strength
- Not detecting jobs: Ensure server is running and jobs exist

Printer Agent Issues:
- Can't download PDF: Check internet connection
- Can't print: Verify printer name and driver installation
- Job not marked as printed: Check server connectivity

Server Issues:
- Can't start: Check PORT and environment variables
- API errors: Check Cloudinary credentials
- Jobs not saving: Check file permissions

Common Errors:
- "Connection refused": Server not running
- "WiFi not connected": Wrong SSID/password
- "PDF download failed": Internet connectivity issue
- "Printer not found": Check printer name in config
